The purpose of this assignment is to experiment with the preemptive SJF (Shortest Job First) scheduling algorithm by using different profiles and observing the different outcomes.

Specifically, we used different inputs (processes), such as:

* interactive and non-interactive blocks,
* with or without waiting time in the ready queue,
* different execution times,
* and other varying process characteristics.

Additionally, we recorded the weaknesses and performance of the algorithm based on the Average Turnaround Time.
